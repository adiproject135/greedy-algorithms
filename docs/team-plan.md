# Organizarea echipei

Impartirea de mai jos separa productia materialelor de prezentarea orala.

## Adi - coordonare, documentare si analiza

- Structureaza proiectul si stabileste continutul.
- Cauta si verifica informatiile teoretice.
- Analizeaza complexitatea temporala si spatiala.
- Construieste exemplele in care strategiile alternative esueaza.
- Compara Greedy cu alte abordari si verifica integrarea tehnica.
- Prezinta analiza, limitele, comparatiile si concluziile.

## Andrei - prezentare si fundamente teoretice

- Construieste slide-urile pe baza structurii si materialelor centralizate.
- Se ocupa de organizarea vizuala si coerenta prezentarii.
- Explica tehnica Greedy, proprietatile si argumentul de corectitudine.
- Verifica impreuna cu echipa daca slide-urile reflecta corect implementarea.

## Eca - implementare si demonstratie

- Dezvolta Jupyter Notebook.
- Explica implementarea Activity Selection.
- Pregateste exemplele de test si rularea live.
- Prezinta implementarea si demonstratia practica.

## Etape comune

1. Confirmarea continutului si a problemei.
2. Documentare, slide-uri si notebook in paralel.
3. Verificarea codului si a exemplelor.
4. Integrarea materialelor intr-o singura prezentare.
5. Repetitie comuna si verificarea intrebarilor posibile.

## Verificare reciproca

Responsabilitatile principale nu inseamna ca membrii cunosc doar o treime din proiect. Inainte de prezentare, fiecare trebuie sa poata explica:
- de ce criteriul Greedy ales este potrivit pentru Activity Selection;
- de ce alte criterii locale pot esua;
- de unde provine complexitatea;
- de ce 0/1 Knapsack este un exemplu de problema pentru care euristica raportului valoare/greutate nu garanteaza optimul.
